# Domain Docs

This repository contains one shared LAB-HUB domain across its web, API, mobile,
and shared packages. Treat it as a single context unless a future domain map is
introduced.

Before exploring a change, read the relevant documents under `docs/`, especially
the architecture and clinical-analysis flow documents. Use the established
terms `paciente`, `agendamento`, `coleta`, `resultado`, `laudo`, `declaração`,
`LIS`, `FlowLab`, and `portal do paciente` in issues and specifications.

No root context glossary or ADR directory currently overrides those documents.
