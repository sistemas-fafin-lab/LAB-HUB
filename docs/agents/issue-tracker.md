# Issue tracker: Local Markdown

Issues and specs for this repository live as Markdown files under `.scratch/`.

## Conventions

- One feature per directory: `.scratch/<feature-slug>/`.
- The feature spec is `.scratch/<feature-slug>/spec.md`.
- Implementation tickets live one per file under `.scratch/<feature-slug>/issues/`, numbered from `01` in dependency order.
- Triage state is recorded with a `Status:` line near the top of each ticket.
- Comments and conversation history are appended under a `## Comments` heading.
